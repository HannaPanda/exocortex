The attention inbox ("Wartet auf dich"): one list, across all workspaces, of what needs a person's action right now. Each entry is a decision, an approval, a result to review, a blocked work item ("Auftrag"), a failed AI run or a question from an agent, with buttons to answer it in place. Kind labels are short and sit in badges; buttons are short imperatives or noun phrases ("Abnehmen", "Neuer Versuch"). Hints are full sentences addressed to the person with "du". "Agent" is an external agent account such as Claude Code or Hermes, "KI" the built-in AI, "Lauf" one AI run.
