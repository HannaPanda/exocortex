The diagnosis of an AI run that ended without an answer, shown in the chat panel in place of the error message and returned to agents by `exo_ai_run_get`: why the run hit its tool-call limit (which tools it spent its calls on, how many answered nothing new) or its time limit (which limit, at which thinking level, whether any text had arrived), each followed by what to try instead. Full sentences for the person; tool names such as `exo_search`, setting keys such as `ai.timeoutMs` and the model slug in `{model}` stay as they are, and `effort` holds the thinking-level labels exactly as the model picker says them.
