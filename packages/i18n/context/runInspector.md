The run inspector: one screen that shows what a run of the built-in AI did and what its prompt was made of, as a timeline of model turns and tool calls with sizes, durations, providers and costs, never the text itself. Labels are short and technical but in plain German; "Lauf" is one run of the built-in AI, "Modellrunde" one exchange with the model, "Werkzeug" a tool it called. The two link labels appear next to a run in a work item and under an answer in the chat.
