The work items screens of a workspace ("Aufträge"): delegated work handed from a person to an agent, the built-in AI or another person, and back. There is a dense list with filters, a detail view with status, reason, acceptance criteria, result, AI runs, sub-items and a history, and a dialog to create or edit one. Status labels are short and sit in badges; history lines continue a name ("Johanna hat den Status … gesetzt"), so they start lowercase with a verb phrase. Hints are full sentences addressed to the person with "du". "KI" is the built-in AI; "Agent" is an external agent account such as Claude Code or Hermes.
