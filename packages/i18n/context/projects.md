A LaTeX project workspace: a toolbar with the main file, engine and bibliography choice and a build button, a file tree, a collaborative source editor, and a panel with the built PDF, the error list, the raw log and the build history, plus dialogs for creating a file and for the report after importing a ZIP archive. Labels are short, status labels lowercase in a badge; empty states and hints are full sentences addressed to the person with "du". LaTeX vocabulary stays as it is: pdfLaTeX, XeLaTeX, LuaLaTeX, BibTeX, Biber, SyncTeX, UTF-8, ZIP; "Bauen" (build) is the verb for compiling, and the example path may be localised.
