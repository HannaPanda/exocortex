The feature registry's words: for every capability of this deployment a title, a one or two sentence summary, several paragraphs explaining how it works, how you use it and where it stops (`details.p1` onwards), and a sentence saying where in the interface it is found (`where`), shown on the help page (`/hilfe`) and returned to agents by the `exo_features` tool. They are addressed to the person with "du", keep product, tool and setting names such as `exo_page_write`, `Strg+K` or `ai.pageContextEnabled` exactly as written, and quote interface labels the way the interface in that language would show them.
