The page editor: the slash menu with its block names and one-line descriptions, the formatting toolbar over a selection, the block handle and its actions, the table and code block toolbars, the link editor and the dialogs that follow a link, the `@` mention menu, page link and embedded-content blocks, and the confirmation before a larger block is deleted. Block names, menu items and button labels are short labels in the style of a word processor; descriptions, empty states and confirmations are full sentences addressed to the person with "du". Keyboard shortcuts name the keys the way the language's keyboards print them (German "Strg" is "Ctrl" in English).
