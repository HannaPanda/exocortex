Agent workflows: a visual editor for graphs of nodes (triggers, agent steps, conditions, parallel branches, joins, approvals, end) and a debugger that shows a run on its graph. "Workflow" stays as the technical term; a "Knoten" is a node, a "Verbindung" an edge, a "Lauf" one run, a "Probelauf" a test run, "Entwurf" the editable draft, "Version" a published immutable version, "Freigabe" here always means an approval a person decides (never a share), "Auftrag" a work item handed to the assistant.
