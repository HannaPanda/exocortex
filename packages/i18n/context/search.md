Finding things again: the command palette with full-text search and recently edited pages, the search area with its query builder (filters by place, type, database properties, entities and time window), saved searches, smart views in the navigation, and query blocks embedded in a page that show a saved search's current results. Labels and filter options are short and lowercase where they complete a sentence ("überall", "letzte 7 Tage"); hints and empty states are full sentences addressed to the person with "du", and they stress that a saved search stores the question, never the answers.
