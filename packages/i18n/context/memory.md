The memory screen (`/gedaechtnis`): the facts the agents distilled from their session notes, filtered by project and status, each with its confirmations, weight, last confirmation and sources, and a button to promote a fact into a curated workspace. Statuses ("gilt", "überholt", "widersprüchlich") are short lowercase badges; the intro and empty state are full sentences addressed to the person with "du". "Memory" in "Memory-Arbeitsbereich" is the name of the agents' workspace.
